# ConEmu

Windows console emulator (C++, Win32 API, Visual Studio solution). Development branch: `daily`; `master` is moved to `daily` on release.

@CLAUDE.local.md

## Layout
- `src/CE.sln` - main solution (generated by `premake5.exe vs2019` from `premake5.lua`; projects are `src/*.vcxproj`). Configurations: `Debug`, `Release`, `Remote`; platforms `Win32`, `x64`.
- `src/ConEmu` - GUI (`ConEmu.exe` / `ConEmu64.exe`). `src/ConEmu/About.h` has the command line switches help.
- `src/ConEmuC` - console server/client (`ConEmuC*.exe`); `src/ConEmuCD` - server dll; `src/ConEmuHk` - hooks dll (injected into console processes).
- `src/common` - shared code (`common-kernel`, `common-user` static libs).
- Far Manager plugins: `ConEmuDW` (Far.ExtendedConsole, TrueColor API), `ConEmuPlugin` (tabs, macros, integration), `ConEmuLn` (visual tweaks), `ConEmuTh` (thumbnails/icons). Build them only when testing Far integration.
- `src/Tests.vcxproj`, `src/UnitTests` - googletest based unit tests (submodule `src/modules/googletest`). Not all tests are green yet - failures may be pre-existing, check before blaming your change.
- `src/modules/*` - git submodules (minhook, json-parser, rapidxml, terminals, googletest). Do not edit.
- `Deploy/` - release/deploy scripts, l10n scripts. `Debug/` (repo root) - local build output, gitignored.

## Build
- Debug output goes to `<repo>/Debug`. Minimal local set on x64 host: `ConEmu` (x64), and `ConEmuC`, `ConEmuCD`, `ConEmuHk` for x64 and x86. Release builds are rare (performance tests only).
- `Remote` configuration links into `Z:\` (maps to `C:\ConEmu` on the remote test machine). It is compiled on THIS host, not remotely. Same project set as above: x64 minimum, add x86 `ConEmuC/CD/Hk` for the full cycle (e.g. 32-bit cmd.exe test).
- Release is built by `src/vc.build.release.cmd` (nmake, `makefile_all_vc`). For Debug/Remote use msbuild via `src/ms.build.dev.cmd`.

## Run / test
- Smoke test: `ConEmu64.exe -basic -run cmd.exe` (default settings, cmd as shell). `-run` must be the LAST switch.
- Command line switches: always write them in `-switch` form (not `/switch`) in docs, scripts and examples.
- Custom settings: named xml next to the exe + `-loadcfgfile <file>`.
- Remote test machine: started over ssh from the host (see `CLAUDE.local.md`).

## Conventions
- Follow the style of the surrounding code; `.editorconfig` has priority (cpp/h: tabs, CRLF, UTF-8, final newline; others: 2 spaces).
- Code comments: new comments are written in English. When editing a source file, translate Russian comments in the code surrounding your changes to English (only the nearby code, do not translate the whole file).
- `src/ConEmu/version.h` is changed ONLY by the release script. Never edit it by hand.
- Localization (`l10n`) is synced with Transifex via scripts in `Deploy/` (`l10n_*.cmd`, `l10n.py`). English is the source language; new English strings are added to yaml via a ps1 script. Ask before touching GUI dialog strings/resources.
- Git history must be flat: no merge commits, rebase only (accepting user PRs, merging features).
- Do not change `.vcxproj` files by hand unless asked; they are generated by premake.
